# 计算机视觉与深度学习入门

本章节涵盖了从最简单的 MLP 到 CNN 的演进。

## 1. MLP：神经网络的“Hello World”
对应代码：`src/cv/02_mlp_mnist.py`

### 核心原理
我们把一张 28x28 的图片，看作是 784 个数字组成的**一长串列表**。
*   **输入层**：784 个神经元。
*   **隐藏层**：通过矩阵乘法 ($y = Wx + b$) 和激活函数 (ReLU)，提取非线性特征。
*   **输出层**：10 个神经元，分别代表这张图是 "0" 到 "9" 的概率。

**缺点**：破坏了图片的**空间结构**。像素点 (0,0) 和 (0,1) 本来挨着，展平后虽然还在旁边，但 (0,0) 和 (1,0) 就隔得很远了。

## 2. CNN：为图像而生
对应代码：`src/cv/03_cnn_cifar10.py`

### 核心组件
1.  **卷积层 (Convolution Layer)**: 
    *   想象一个小手电筒（卷积核 Kernel），在图片上滑动。
    *   它可以检测特定的特征，比如“竖线”、“横线”、“圆弧”。
    *   参数共享：同一个卷积核在整张图上通用，大大减少了参数量。
2.  **池化层 (Pooling Layer)**:
    *   把图片缩小（下采样）。
    *   保留最重要的特征（Max Pooling），丢弃不重要的细节。
    *   让模型具有“平移不变性”（猫在左上角还是右下角，都能识别出是猫）。

### 数据流向图
```
Input Image (32x32 RGB)
    |
[Conv2d] -> 提取特征
[ReLU]   -> 激活
[Pool]   -> 缩小到 16x16
    |
[Conv2d] -> 提取更高级特征
[ReLU]
[Pool]   -> 缩小到 8x8
    |
[Flatten] -> 展平成一维向量
    |
[Linear]  -> 分类
    |
Output (10 classes)
```

## 3. 练习建议
1.  运行 `src/cv/02_mlp_mnist.py`，观察准确率能达到多少 (通常 >95%)。
2.  运行 `src/cv/03_cnn_cifar10.py`。你会发现 CIFAR-10 比 MNIST 难得多，简单的 CNN 可能只能达到 60%-70% 的准确率。
3.  尝试修改 CNN 的结构：增加一层卷积层，或者把通道数 32 改成 64，看看效果会不会变好？
